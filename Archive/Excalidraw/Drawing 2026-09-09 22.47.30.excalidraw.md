The BPE mechanism is interesting because merging doesn't just happen between VQ-VAE tokes (then every BPE token would have a max length of two). Other BPE tokens can also be merged to form even larger BPE tokens. The more merges we have, the more common these large BPE tokens occur. ^GWvvrjER

Original VQ tokens ^4sDBPbok

BPE Tokens that aren't super large ^NYeFDjcy

Getting bigger... ^GoTa6vNU

"High" BPE tokens that represent larger time series patterns ^KIZXllIj

Y axis represents number of VQ tokens that each token represents ^HyTVpgiI

Obviously have length one becauseo one VQ token represents one VQ token ^lFXXgS1L

x axis is the index of the token in the codebook ^U3vv9RtX

After the original VQ tokens, each new token in the codebook is generated via a single BPE merge. The later tokens are merges of merges of merges (and so forth), explaining their size. ^UV2LPV9D
