Given time series data (continuous or discrete), sample a set of points and create distinct bins on non-time axis of data. Following the order of discrete sampled points, assign an ID to each point based on the bin it falls in. The result is a sequence of IDs representing the time series data.

**Remember:** Tokenization is the process of breaking down data into an ordered list of IDs.
